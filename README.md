# State-Space Trajectory Dataset Generator

Python tools for deterministic Cartesian target trajectories generated by linear state-space models. The state is

```text
x[k] = [px[k], py[k], vx[k], vy[k]]
```

and the measurement is

```text
y[k] = [px[k], py[k]] + v[k]
```

where `v[k]` is zero-mean isotropic Gaussian noise. Measurement uncertainty is specified directly through its standard deviation in metres.

## Files

```text
trajectory_dataset_core.py
    Common state-space models, dataset saving and plotting utilities.

generate_ou_range_dataset.py
    OU-only trajectories. Each trajectory receives one cruise velocity sampled
    independently from user-defined x/y ranges.

generate_three_model_dataset.py
    Dataset containing three trajectory classes, with one model per trajectory:
      1. OU with variable cruise velocity;
      2. CT with fixed positive turn rate;
      3. CT with fixed negative turn rate.

generate_switching_three_model_dataset.py
    Each trajectory switches internally among OU, CT positive and CT negative.
    A new OU cruise velocity is sampled whenever a new OU segment starts.
```

All generators use the same main `.npz` schema, so the same loading and evaluation code can be reused.

## 1. OU-only dataset with variable cruise velocity

Windows Command Prompt, one line:

```bat
python generate_ou_range_dataset.py --length-mode variable --min-len 200 --max-len 300 --batch-size 1000 --sampling-time 1 --ou-gamma 0.05 --ou-vx-min 4 --ou-vx-max 12 --ou-vy-min -4 --ou-vy-max 4 --measurement-std 0 1 2 3 5
```

The cruise velocity is constant within each trajectory but varies across trajectories:

```text
dx ~ Uniform(ou-vx-min, ou-vx-max)
dy ~ Uniform(ou-vy-min, ou-vy-max)
```

## 2. Three-model dataset with one model per trajectory

```bat
python generate_three_model_dataset.py --length-mode variable --min-len 200 --max-len 300 --batch-size 999 --sampling-time 1 --ou-gamma 0.05 --ou-vx-min 4 --ou-vx-max 12 --ou-vy-min -4 --ou-vy-max 4 --ct-turn-rate-deg 3 --measurement-std 0 1 2 3 5
```

The dataset is balanced as closely as possible across:

```text
ou
ct_positive   (+3 deg/time-unit in the example)
ct_negative   (-3 deg/time-unit in the example)
```

For exact balance, use a batch size divisible by three.

## 3. Three-model dataset with switching inside each trajectory

```bat
python generate_switching_three_model_dataset.py --length-mode variable --min-len 200 --max-len 300 --batch-size 1000 --sampling-time 1 --ou-gamma 0.05 --ou-vx-min 4 --ou-vx-max 12 --ou-vy-min -4 --ou-vy-max 4 --ct-turn-rate-deg 3 --switch-min-duration 20 --switch-max-duration 50 --measurement-std 0 1 2 3 5
```

Each trajectory is divided into piecewise-constant dynamic segments. The active model is one of:

```text
ou
ct_positive
ct_negative
```

By default, every trajectory contains all three models at least once. This requires

```text
minimum trajectory length >= 3 * switch-min-duration
```

Use `--allow-missing-models` if this guarantee is not required.

At an OU segment transition, the cruise velocity is sampled again:

```text
dx ~ Uniform(ou-vx-min, ou-vx-max)
dy ~ Uniform(ou-vy-min, ou-vy-max)
```

The state remains continuous at every model switch. Only the transition model and its parameters change.

## Saved data

Each `.npz` file contains the common fields:

```text
states                    (N, T, 4)
observations              (N, T, 2)
mask                      (N, T)
lengths                   (N,)
transition_matrices       (N, T, 4, 4)
input_matrices            (N, T, 4, 2)
control_inputs            (N, T, 2)
turn_rates_deg            (N, T)
active_model_ids          (N, T)
active_model_codes        (N, T)
trajectory_model_ids      (N,)
trajectory_model_codes    (N,)
measurement_noise_std     scalar
```

The switching generator additionally saves:

```text
segment_ids                       (N, T)
switch_flags                      (N, T)
ou_cruise_velocities_per_step     (N, T, 2)
```

Model codes are

```text
ou           = 0
ct_positive  = 1
ct_negative  = 2
pad          = -1
switching trajectory label = -2
```

For a variable-length trajectory:

```python
import numpy as np

data = np.load("data/example.npz")

i = 0
Ti = int(data["lengths"][i])
x_i = data["states"][i, :Ti]
y_i = data["observations"][i, :Ti]
models_i = data["active_model_ids"][i, :Ti]
switches_i = data["switch_flags"][i, :Ti]
```

For every valid transition, the stored ground-truth model satisfies

```python
x_next = F_k @ x_k + B_k @ d_k
```

with

```python
F_k = data["transition_matrices"][i, k]
B_k = data["input_matrices"][i, k]
d_k = data["control_inputs"][i, k]
```

## Output files

For each value supplied to `--measurement-std`, each script saves:

- one compressed `.npz` dataset;
- one `.png` plot of the trajectory selected by `--plot-sample-index`.

The default measurement-noise levels are:

```text
0, 1, 2, 3, 5 m
```

## Modelling assumptions

- State and observation models are linear conditional on the active model and its parameters.
- Process noise is zero.
- CT positive and CT negative use equal turn-rate magnitude and opposite signs.
- In the switching generator, the dynamic state is continuous across model changes.
- The final segment can be extended slightly when the remaining trajectory length is shorter than the requested minimum dwell time.

### Common measurement-noise realization

All datasets generated in the same run share a single standard-normal
measurement-noise realization.

For each measurement-noise standard deviation `sigma`, observations are
generated as

```text
y[i, k] = position[i, k] + sigma * epsilon[i, k]
